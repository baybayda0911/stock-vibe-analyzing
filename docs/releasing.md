# 发布清单与分发核验



本仓库只分发研究工作流、档案管理工具、本地工作台程序与维护文档。基本面与技术面形成专业研究，研究室回顾旧判断及反馈，档案室定位／比较／导出和恢复文件。公司研究报告、金融原始数据、图表样本、模型运行记录、认证资料、本机管理资料、私有查阅页面、快照和恢复副本不进入源码提交或 Release 附件。



0.15.0为S1—S5验收修订，在已有经营／技术看板、连续研究、正式补充归档、Codex／DeepSeek持久任务和2—5股只读比较上，增加视图偏好与档案关键词并修复旧项回顾边界。app共十九文件，加通用start-platform.cmd为二十必需运行资源。四独立Skill包自包含，基本面0.3.2／研究室0.3.0／技术面0.4.2／档案室0.3.0，不夹带平台代码；核心只需标准库，PDF提取是已有PyMuPDF可选能力，缺失不自动安装。功能与实际测试以[验证记录](validation.md)为准。



本版对齐D5四主入口及个股科目，经营、技术和首页总览沿原归档来源。价格图有真实60观察窗口、价格／MA5图例和日期，不将虚构布局曲线填进生产。持续研究保留跨全部旧档的原判据、冻结日、证据覆盖、正式回顾与下一步，不把检查候选当正式评价。研报显式检查、有限公开PDF取得及source-only缓存不是新专业研究；满足明确宿主兼容门槛后可由用户正式归档broker_source补充成果，原发布日期保持且不替代正式基本面。注册原件随对应成果导出及既有快照/2保存；partial原件导入不能当完整归档。S4研究仅在用户明确开始后执行，依据可信冻结档案与组件；不主动Web／Wind取数、后台刷新行情或重算技术指标。旧材料截止与本次生成日分开，无量化材料保留问题卡。研报驱动必须选择已核且正式归档的来源，本版broker_update只作source_adaptation，不替代正式基本面。S5比较仅复用共同观察日可见的正式组件，统一财报期、累计／单季／全年及人民币元；合并现金转化分母、归母利润、原价共同窗和来源日期各自核对。PE股本／股类、原估值情景与各自技术链不兼容时不可排名，原价基100不代表含息总收益或复权认证。比较不调用模型、不新取数、不改原档或名单，实际内测另记。



补充归档门槛使用`stock-research-role-resolver/1`共享能力，并核对明确配置的Codex与Trae两处安装及各34资源指纹；缺失、变化或能力不符时保持关闭。当前两端已备份后安装并核验，此结论限本次配置，不保证所有宿主或后续版本持续兼容。Trae未重做对话验证，不保证已打开客户端热加载。安装记录与公开分发分别管理。



私有根、CSV原数、研报PDF及提取、broker-cache暂存、`platform/watchlist.json`、`_workspace/platform`下的服务状态／日志／访问凭据，以及机器专用隐藏窗口脚本或快捷方式均不分发。原生Codex会话继续使用原HOME，不把会话数据库或后台项目标识加入发布文件。研究任务、attempt冻结材料、恢复状态和引擎配置同样属于私有工作区，不随源码、独立Skill或正式档案快照分发。两来源使用各自独立线程并核同一专属后台项目，保留现有认证和全局配置，不提供另一个OpenAI API Key路径。



## 明确的发布白名单



[release-files.txt](../release-files.txt) 逐文件列出拟公开内容。准备发布时人工审查清单及文件内容；只按清单暂存文件，不使用无范围的全量暂存。`.gitignore` 是辅助规则，不能代替实际提交树和归档内容核验。



维护脚本、S5本机平台、研究室及档案室工具需要Python 3.10+标准库，基本面独立研究不因此要求Python。技术面完整数值与出图按包内[requirements.txt](../skills/stock-technical-analysis/requirements.txt)在独立环境准备；不改其他项目的基础环境。先冻结本次文件和版本、完成审阅，再在仓库根目录执行：



```powershell

$technicalPython = '<已准备的技术独立环境Python绝对路径>'

& $technicalPython -X utf8 -B -m unittest discover -s tests -v

& $technicalPython -X utf8 -B scripts/build_release.py --output '../release-artifacts/stock-vibe-analyzing-0.15.0' --skill stock-fundamental-analysis --skill stock-research-lab --skill stock-technical-analysis --skill stock-research-archive

```



输出目录必须在仓库外且不能覆盖同名附件。默认仍生成源码、基本面包与校验和；可重复`--skill`明确选择基本面／研究室／技术面／档案室。当前源码白名单99文件；基本面包六文件、研究室包六文件、技术面包十五文件、档案室包七文件，共34资源，各自按metadata.version命名，校验成员、字节、许可及ZIP完整性。平台十九文件加通用启动器为明确二十个必需运行资源，不能把允许HTML／JS／CSS／CMD扩大到名单外文件；任意金融HTML或运行产物不随源码发布。各包相对链接只能引用自身明示成员；技术包保留第三方许可，真实图表、JSON与行情不入包。



技术包包含入口、MIT、第三方说明、元数据、两本说明书、依赖清单及八个脚本，新增行业比较与简明报告组件；没有运行环境、wheel、行情、案例或档案。源码另含对应测试。隔离解包时检查研究室CLI、原谐波CLI、综合技术CLI及行业工具的`--help`能在`-I -S`下运行，共用模块也须可隔离导入。缺数值依赖时主指标明确未运行；帮助通过不能写成TA-Lib数值、61类蜡烛或真实图表通过。



档案室包包含SKILL.md、LICENSE、agents/openai.yaml、references/档案室说明书.md，以及`research_archive.py`、`archive_views.py`、`archive_backup.py`三个脚本。隔离解包检查其`--help`及包内模块导入；实际`view/compare/export/backup/verify/restore`须显式传入已核验的研究室工具绝对路径`--lab-tool`，不能依赖两个包相邻，也不能将私有根配置塞进包。档案室复用一套源记录和一个可重建catalog；根内`_workspace/views`、`_workspace/backups`、`_workspace/restore-tests`属于私有运行产物，不是源码资源。完整文件快照与新目录恢复单独验收，同盘副本不视为硬盘故障容灾。

## S1—S5验收修订的分发核对

新增视图偏好和档案关键词功能只复用现有静态资源，源码白名单仍99、运行资源20、Skill资源34。偏好仅同浏览器同origin有效，不存报告、凭据、草稿或回答，不自动执行或恢复研究；源代码包不能包含localStorage快照。档案搜索只匹配已加载元数据，不把PDF／金融原始文件加入公开包。延续研究超50旧项须在模型前阻止并明确分批，页面历史回顾不能重激活旧资格，需保留相关边界回归。

本轮用户授权推送源码提交及按版本命名标签；核验通过后标签应为v0.15.0。推送与GitHub Release附件发布、全局Skill安装各是独立动作；只完成Git推送时，不得写成附件已发布或四Skill已重新安装。

## 提交与发布



1. 按维护规则完成结构、安装隔离及实际相关行为验收，更新验证记录和 CHANGELOG。

2. 完成独立文件安全复查并交付脱敏报告；该阶段完全不执行 Git。

3. 进入已另行明确授权的 Git 发布阶段，核对目标身份、远程默认分支、历史和工作区，保留已有文件及本地资料。

4. 逐文件暂存白名单。实际提交树应与白名单完全一致；已有远程历史另行核验，不以当前树干净推断历史无敏感内容。

5. 提交后再次确认没有 reports、data 或其他清单外文件。标签使用 `v` 加 VERSION 中的版本，指向经核验的仓库提交；不覆盖已有标签或强制推送。

6. 按授权正常推送并上传所选ZIP及SHA256SUMS.txt。下载远程附件核对哈希与成员；自动生成源码归档也核对成员。
