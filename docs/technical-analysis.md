# 技术面分析

`stock-technical-analysis` 0.5.0是A股优先的独立研究Skill，正式采用已确认的简报结构，提供六个有限专题、四项研究输出，当前聚焦日／周／月／半年／年线。分钟研究、缠论、基础波浪及高级波浪暂停；两个波浪只在Longbridge公开资源完整后重新评估，不自动接入。它没有行情服务、券商、后台任务或完整交易平台。

方法、参数、请求模板及读图统一维护在包内[技术面分析说明书](../skills/stock-technical-analysis/references/技术面分析说明书.md)，谐波细则见[谐波专题说明书](../skills/stock-technical-analysis/references/谐波专题说明书.md)，宿主流程见[技术Skill入口](../skills/stock-technical-analysis/SKILL.md)。

## 四输出与研究方式

默认阅读`report.html`或`report.md`：先回答技术偏强、偏弱、分歧或暂不能判断，给出关键理由，再阅读价格趋势及相对表现两类主图、各周期简表和下一步观察／确认／失效条件。主图各配简短解读；不要求读者先理解全部专题术语。主周期趋势采用明示价格／均线条件，不能用所有专题投票；分钟暂停不抹掉合格日线结论。

`details.html`保留六专题、各周期完整图表、读图解释、方法及证据支持冲突表，正文可按需进入。完整参数、状态、来源和审计数值保留在`analysis.json`。正文和附录来自同一冻结结果，增加图表不增加独立证据。

可选前次快照比较核证券、股类、币种、日期、来源谱系、窗口及价格基准兼容声明；不兼容时只给历史回顾与原因。动态均线变化不当作突破旧静态阈值，原观察没有预测定义就不计命中。归档按信息截止放研究日期目录，实际生成日分别记录；更正以新版本保存，旧档不覆盖。

1. 市场／行业背景：冻结共同窗口、基准身份及价格口径；可使用明确标记的自建申万标签行业组合，缺行业不编排名，缺基准仍可独立研究个股。
2. 证据支持冲突表：围绕命题列事实、来源、时点、同源依赖和反证；期限不同、口径不一致与真实矛盾分开。
3. 按需执行条件卡：纯研究不问持仓；个性化动作缺必要资料、原价映射或适用制度时保留非个性化条件，不造数量或默认仓位。
4. 严格复盘：分别记录条件结果、采纳、执行事实、五类问题和收益资格；缺反馈不是未做，未交易不是0收益。

支持单股深研、指定2—5只比较，以及用户明确证券池和条件的筛选。不可比证券单独说明，不排统一总分；不默认全市场运行。本地资料优先，必要日线或基准缺口使用Wind时先做最小字段／延迟／费用探针，未知费用不写免费，也不自动扩大区间或换数据商。当前不为技术研究读取或请求分钟数据。

## 自建行业比较

本地行情的逐日申万一级／二级／三级名称可作为分组标签。行业工具按前一共同交易观察日的行业归属、个股当日收盘与前收参考价收益，构建等权行业比较组合，并输出行业广度与覆盖率。它不整体运行外部选股平台，也不改变个股六专题算法。

输出明确标为**自建等权申万标签组合，非官方申万指数**；非全收益指数，也不表示可按图成交。行业分类、成分有效数、缺失收益、链段重置及目标股是否被包含分别保留。若行业组合包含目标股，其相对表现不能作为完全独立的证据。历史分类可知性未核实、存续样本或数据缺口仍须说明，不能用今天取得的文件宣称历史当时已有同版分类。

## 数据和运行

日、周、月、半年及年线各自核证券、时间语义、会话、完成、复权、可得和缺口。默认周期枚举为`1d`／`1w`／`1mo`／`6mo`／`1y`；计算支持不等于每种来源均已验收，快照今天取得不证明历史当时已有同版数据。

周／月聚合保留真实端点和缺失规则。半年／年额外要求交易日历覆盖完整期间，只把最近连续完整段送入计算；旧的完整断段与未完成自然期间、缺交易日、日历未覆盖分别记录，不填停牌日或缺年。缺少最新应有完整期间时，明确实际`data_asof`及历史端点。年线MA20需要20根连续完整年线；数据不够时留空，不能把断续20根解释成连续20年，也不强行运行所有专题。

5／15／60分钟请求返回`paused`，不读取输入、不取数、不计算、不聚合，主报告不再展示价格采样图。旧分钟档案仍可回顾，历史兼容解析保留；它们不会因此升级为新的分钟研究。任何close-only资料都不构造OHLC、ATR、蜡烛或高低结构。原价／复权未核、机械缺口未排除或过期行情仍是诊断，长周期聚合不提升其资格，不作当前个性化执行依据。

技术独立包十五资源须完整，包含八脚本、两本说明书及[依赖清单](../skills/stock-technical-analysis/requirements.txt)。帮助、输入门和部分计算仅需标准库；完整指标／蜡烛需NumPy与TA-Lib，图需Matplotlib与Plotly。依赖放独立环境，缺少时明确未运行，不自行安装。当前开发文件不自动替换全局Skill；宿主自动调用另行验证。

行情、请求、报告、计算JSON及图保存在不存在的非Git私有输出目录，CLI拒绝覆盖或写入源码／安装目录。PNG和自含HTML对应同一冻结结果；A股主图转换为UTC+08:00并标注，JSON保留实际时点，其他市场主图标UTC。未来D不配虚构日期，完整状态与失败原因保留JSON。详细命令、输出文件及比较／筛选协议以包内说明书为准。
