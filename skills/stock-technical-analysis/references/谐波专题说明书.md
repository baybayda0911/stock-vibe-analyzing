# 谐波专题说明书

适用`stock-technical-analysis` 0.4.1；谐波规则`project-harmonic-v1` 1.0.0。本说明书专讲四类谐波；六专题、四输出及研究室接合见[技术面分析说明书](技术面分析说明书.md)。缠论、两个波浪和分钟研究暂停。

## 1. 怎么提出请求

可以说：

> 请对这只A股做日线谐波分析，使用已核验复权的本地OHLC，说明候选PRZ、确认时间、失效条件及与上次的变化。

也可以指定证券和周期，例如“请分析中际旭创日线谐波”。宿主会先核对代码与数据，不能只因名称相似就混用证券。需要交易操作分析时，再补持仓、可卖数量、成本、仓位、计划期限和可承受损失；一般研究不需要这些个人信息。

综合入口聚焦日、周、月、半年及年；分钟请求暂停而不计算。数学核心保留历史解析兼容，不代表开放盘中研究。下述harmonic_analysis.py单项入口同样拒绝分钟，非日线及未核原价仍按数据门保留诊断限制。半年／年历史或摆动不足时明确无可运行资格，不补造形态。

## 2. 先检查这五项

|项目|为什么要看|
|---|---|
|证券及股类、币种|相似名称、跨市场挂牌和不同股类不能共用价格几何|
|研究截止、快照最早可得、行情末端|今天生成的报告不代表行情新；后来取得或后来复权的数据不能伪装成历史当时已知|
|周期与K线是否完成|未完成极值会变化；分钟起始标签不能当结束时刻|
|复权方式与依据|除权跳变会制造假形态。几何可用复权序列，执行价另需同日原价转换，不能拿复权价直接下单|
|规则、反向阈值及容差|不同尺度有不同结构；不能为了找出漂亮形态反复调参后只保留成功版本|

`geometry_price_basis_qualified`只表示传入的复权核验声明通过，工具没有自动验证数据商、除权因子、行业规则或交易可行性。`freshness=requires_source_calendar_review`始终要求宿主结合来源和交易日历审查；不凭一个布尔值宣布可以交易。原价或未核验复权明确降级为诊断。

## 3. 图上每一项是什么意思

|图中元素|读法|常见误读|
|---|---|---|
|红涨绿跌K线|本版按A股习惯，收盘相对开盘涨为红、跌为绿|红色不是系统买入提示|
|X、A、B、C、D|五个交替摆动点；线连接价格极值发生位置|画在极值日不代表当天已确认|
|彩色实线、实心点|完整五点通过项目比例，D也在随后反向阈值触发时确认|不是反转或盈利确认|
|彩色虚线、空心点|形成中XABC或活动D预览，后者仍可修改|不能混入已确认样本计算胜率|
|琥珀色横带PRZ|各项D价格条件的共同可行区域，从候选可知时开始标示|不是确定底部、目标价或支撑必守|
|`scenario_status=invalidated`|几何历史仍成立，但后续严格越过所设不利界|不能只读geometry_confirmed就当当前仍有效|
|图例及页眉|证券、周期、复权、状态和数据资格|报告日期不能代替行情末端|

候选D尚未出现时，只给价格集合，没有虚构未来发生日；图不把预估D放到某个未来日期。实际活动D可以画在已发生的K线上，但用预览样式。PRZ在情景失效时停止延伸，保留历史痕迹；完整事件另查JSON。

交互图可缩放、拖动、点击图例及悬停查看点的发生／确认字段；HTML内嵌绘图库，打开无需联网。静态PNG便于报告评审。图选择最近180根内新出现的候选及当前形成中候选，最多4个，显示窗口至少保留所选X点。久远形态仍留JSON，不为了画一条旧线压缩十余年行情；**完整检测集合、比例和失败原因以analysis.json为准**，不能由截图推断全市场或全尺度无形态。

## 4. 四种形态与项目规则

所有比例用绝对段长；如AB/XA=`|A−B|/|X−A|`，AD/XA=`|A−D|/|X−A|`。牛／熊镜像同样核验；方向表达潜在反应方向，不等于可执行多／空订单。

|形态|AB/XA|BC/AB|AD/XA|CD/BC|额外约束CD/AB|
|---|---|---|---|---|---|
|Gartley|0.618|0.382–0.886|0.786|1.13–1.618|1.0|
|Bat|0.382–0.5|0.382–0.886|0.886|1.618–2.618|≥1.0|
|Butterfly|0.786|0.382–0.886|1.27|1.618–2.618|≥1.0|
|Crab|0.382–0.618|0.382–0.886|1.618|2.618–3.618|≥1.0|

这是本项目选定的有限变体，包含明确额外约束，不声称是所有谐波流派的唯一标准。目标来源参照[HarmonicPatterns固定提交](https://github.com/djoffrey/HarmonicPatterns/tree/1e0cd81a96132a1c3337dbbfce39f13d4606758b)及原作者公开的[Gartley](https://harmonictrader.com/harmonic-patterns/gartley-pattern/)、[Bat](https://harmonictrader.com/harmonic-patterns/bat-pattern/)、[Butterfly](https://harmonictrader.com/harmonic-patterns/butterfly-pattern/)、[Crab](https://harmonictrader.com/harmonic-patterns/crab-pattern/)锚点。未复制原作者图文，也没有采用网页中的营销胜率。

默认容差`t=0.05`为**对称相对误差**：目标r容许`[r×(1−t), r×(1+t)]`；连续区间`[lo,hi]`扩为`[lo×(1−t),hi×(1+t)]`；单边下界同理。不是绝对±0.05，也不是上游默认单侧偏差或离散Fib表。价格方向、点交替、正价格等几何硬条件不因容差放松。

默认反向阈值5%：极值之后反向达到该尺度才确认前极值。它是未经过收益优化的研究设置，不能把同一5%默认当成适合所有A股、所有周期。容差只准0至10%，反向阈值严格在0至1之间；参数变动保留新快照，不覆盖旧结果。

上游默认单侧容差、Gartley/Bat投影范围、部分预测分支漏检与去重不作为默认继承。本项目重新写有限数值核心，不纳入上游ZigZag、网络和绘图依赖；详见包内第三方说明。

## 5. PRZ如何得到

先由已确认XABC核AB/XA与BC/AB，再把AD/XA、CD/BC和CD/AB逐项转成D的价格约束，结合方向等硬条件求**交集**。空交集就是没有合格PRZ，不能平均几个目标价、取跨越非法空隙的包络或随手加减百分比。

例如某约束允许D在100–104，另一约束102–107，第三约束101–103，则共同区域102–103。只是数学示例，不是证券价格建议。区间的开／闭端点在JSON的`lower_open/upper_open`中保留；图表标签四舍五入仅用于阅读，不能用显示值替代完整精度。当前不做涨跌幅、最小价位或限价订单取整，不据PRZ生成报价。

## 6. 状态、时间和回顾

|输出字段／事件|含义|
|---|---|
|`forming`|已确认XABC满足前提并有共同PRZ；D未确认|
|`active_d_preview`|活动末端D暂时通过完整比例；仍可变化|
|`geometry_confirmed`|D已成为确认摆动点，完整五点通过所有条件|
|`rejected`|前提可审但PRZ或其它必要条件不成立，保留原因|
|`withdrawn`|形成中候选越过不利界，或D确认时未通过完整规则|
|`prz_first_touched`等事件|已知候选之后价格与区域的关系，事件不自动升级为反转|
|`scenario_invalidated`|几何确认后严格越过PRZ不利外沿；保留原确认与失效时间|
|`insufficient_history`|确认摆动点不足，不等于市场没有谐波|
|`no_candidates`|本次连续摆动窗口没有合格候选，不代表所有锚点／尺度都不存在|
|`invalid_input`|核心输入或规则参数不合法，不产出正常判断|

`occurred_at`是极值所在K线；`first_known_at`是点或候选最早可被本算法识别的时刻；`confirmed_at`是确认时刻。回顾从实际可知或确认时点开始，不能从事后D极值日买入来夸大效果。

同一根同时刷新极值并达到反向阈值时，OHLC不知道先高后低或先低后高，本版只更新活动极值并延迟确认；不能事后选择有利路径。相同极值保留首次发生位置；正式点构成不再回写的前缀。研究设置无日历到期自动撤销，旧候选的现实参考性仍需结合时长、新行情和事件复核。

生命周期不是一条必然顺序链：可以未触区即撤销，可以到区后继续跌穿，可以几何确认后失效。`events`保存这些变化，保留失败样本；逐根回放API只证明在同一冻结输入上的因果计算，不证明历史数据供应商当时已提供相同复权序列。

## 7. 本地调用与请求文件

脚本只读取本地CSV或JSON。JSON是按时间严格递增的记录数组，字段为`time,open,high,low,close`；可附`completed:false`与带时区的`available_at`。CSV支持同名英文字段及`交易日期,开盘价,最高价,最低价,收盘价,股票代码`；支持一行来源说明再接中文表头。编码由请求明确指定。缺列、重复时间、非正或非有限数、错误高低关系会拒绝，不静默删坏数据。

请求模板（证券及路径替换为实际值，时间和核验依据须真实填写）：

```json
{
  "security": {"security_id":"000001.SZ","market":"A-share","exchange":"sz","code":"000001","currency":"CNY"},
  "timeframe":"1d",
  "asof":"2026-11-02T23:59:59.999999+08:00",
  "snapshot_available_at":"2026-11-02T20:00:00+08:00",
  "bar_time_semantics":"period_label_date",
  "completion_evidence":"已核对来源的完整日线导出；不含未完成当日bar",
  "session_evidence":"已对照对应交易所、板块及生效日的会话规则",
  "input_file":"daily.csv",
  "encoding":"utf-8-sig",
  "source":"实际来源及导出批次",
  "data_kind":"market",
  "adjustment":{"mode":"qfq","verified":true,"evidence":"实际因子来源、基准日及截至快照时刻的核验记录"},
  "profile":{"reversal_threshold":0.05,"relative_tolerance":0.05}
}
```

不要照抄示例时间或把未核验写成true。`snapshot_available_at`必须不晚于研究截止；行级`available_at`晚于截止的行排除。若只在今天取得一份后来修订或复权的历史序列，不能把快照可得时间回填为过去，需按今天截止做回溯诊断。

日期标签默认以北京时间日末作为保守可得上界，**不是实际收盘时间**。因此下午做当日分析时，只有日期标签的当日bar会被排除；如需当日已完成行情，须先核实真实完成时点，提供带时区的bar结束时间并声明`bar_end_time`，或使用有依据的日线结束时间声明。周、月、半年及年bar的日期必须是本期结束标签，不能用期初日冒充；未核价格或日历的长周期仍仅诊断，分钟研究暂停。

在安装的Skill目录执行：

```text
python -X utf8 -B scripts/harmonic_analysis.py --request-json <私有请求文件绝对路径> --output-dir <尚不存在的非Git私有目录绝对路径>
```

输出四个文件：`report.md`、`analysis.json`、`chart.png`、`chart.html`。JSON包含实际使用的OHLC、输入文件SHA256、截止、声明、规则、参数、所有候选与事件，是私有金融资料。输出目录必须不存在；工具禁止覆盖、写入源码仓库／Git祖先或经链接路径，绘图失败不留下半成品目录。不会联网、自动装包、读账户或下单。

## 8. 怎样据此形成研究结论

报告依次回答：数据是否合格及新鲜→有没有当前可解释的结构→PRZ和首次可知／确认时间→仍有哪些冲突及失效条件→下一次看什么。无候选就据实交付，不调参直到“找到”。

结合A股市场／行业强弱、独立量价事实和已公开基本面看背景。综合入口已实现其余五个有限专题，单项谐波命令本身不运行它们，不能据单项结果声称完成综合核验。持仓操作还需考虑T+1可卖数量、限价、跳空、成交量和规则生效日；看空形态不等于可以做空，失效界也不保证止损成交。

已配置研究室时读旧档、比较原候选及未结项，再归档本次报告与关注项。综合入口结合研究室0.2.0可复制并复验PNG／HTML／JSON附件；兼容单项谐波命令仍只出本地四文件，需要宿主另行archive。实际保存、附件和索引状态分别报告，未入档快照须原地保留。旧结果不能因为再次导出就变新；对照证券、输出日、资料截止、行情截止及失效条件后决定能否引用。

建议每次回顾记录：当时是否有候选、首次可知、是否触区、是否确认、确认延迟、是否撤销／失效、事前明确的价格反应条件是否实现。未事前定义期限或幅度的观察项不计算命中率。当前未做A股样本外收益评价，不提供胜率、收益提升或推荐仓位。
